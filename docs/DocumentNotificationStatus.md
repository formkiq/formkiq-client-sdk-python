# DocumentNotificationStatus

Status of the document notification. WAITING awaits an external trigger and is not eligible for processing. PENDING is ready for processing. ACTION_CREATED indicates that a Document Action has been created.

## Enum

* `WAITING` (value: `'WAITING'`)

* `PENDING` (value: `'PENDING'`)

* `ACTION_CREATED` (value: `'ACTION_CREATED'`)
