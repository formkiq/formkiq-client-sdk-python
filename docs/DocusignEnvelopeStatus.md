# DocusignEnvelopeStatus

Controls how the envelope is created: * `created` saves the envelope as a draft without notifying recipients. * `sent` immediately sends the envelope to recipients.

## Enum

* `CREATED` (value: `'created'`)

* `SENT` (value: `'sent'`)
