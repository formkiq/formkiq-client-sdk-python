# OpaPolicyTestDecision

OPA policy evaluation decision. ALLOW maps to TRUE, DENY maps to FALSE, and PARTIAL indicates that document criteria must be evaluated by the request interceptor.

## Enum

* `ALLOW` (value: `'ALLOW'`)

* `DENY` (value: `'DENY'`)

* `PARTIAL` (value: `'PARTIAL'`)
